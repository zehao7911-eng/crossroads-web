# GameWave import

Upload CROSSROADS-GAMEWAVE.zip as an HTML5 package. Its root index.html contains all required assets and starts without network dependencies. The game uses WebGL, touch controls, and an English interface.

One SDK round is one arena. Live play calls gameStart(). An arena win or loss calls gameOver(). The browser keeps separate Classic and Arcade checkpoints in crossroads-web-v1. The GameWave cloud profile stores medals and cosmetic rewards.

A confirmed like unlocks pink blast effects. A confirmed direct comment unlocks violet knockout effects. Both are optional, and duplicate callbacks do not grant duplicate rewards.
